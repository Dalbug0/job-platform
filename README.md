## Job Platform (черновая версия)

**Направление развития репозитория**: Backend API для агрегации вакансий (HH.ru) + Telegram‑bot как клиентский интерфейс. Компоненты собраны в один проект для удобного развертывания и управления.

Проект находится на ранней стадии и структура, технологии и интерфейсы могут меняться по мере развития.

### Общая идея

- **Backend API**: сервис, который агрегирует вакансии с HH.ru (и потенциально других источников) и предоставляет единый HTTP‑интерфейс для получения и фильтрации вакансий.
- **Telegram‑bot**: клиентский интерфейс к API, позволяющий пользователю искать и просматривать вакансии прямо в Telegram.
- **Единый репозиторий**: backend и bot находятся в одном проекте для упрощения разработки, развертывания (например, через `docker-compose`) и сопровождения.

### Текущее состояние

- **Статус**: ранняя, нефинальная версия, активная стадия разработки.
- **Гарантии**: структура каталогов, технологии и публичные интерфейсы могут меняться без обратной совместимости.

### Планируемое развитие (черновой список)

- **Расширение интеграций**: поддержка дополнительных источников вакансий помимо HH.ru.
- **Улучшение API**: удобные фильтры, пагинация, сортировка, статистика по вакансиям.
- **Развитие Telegram‑бота**: сценарии поиска, подписки на новые вакансии по критериям, сохранённые запросы.
- **Инфраструктура**: более удобные сценарии локального запуска и деплоя (docker, окружения, настройки).
